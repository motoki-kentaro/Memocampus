# ADR: MCP公開時の権限系シークレット保護 — 設計判断保留

- **Status:** Deferred（PO判断保留）
- **対象:** Memocampus Issue #14
- **決定日:** 2026-11-13
- **決定者:** PO
- **根拠:** Slice 0調査、Slice 1A詳細設計・隔離PoC、Claude／Gemini／GPTによる設計レビュー

## Context

MemocampusはWeb閲覧履歴を忠実に保存し、ユーザーが許可したデータをMCP経由でAIに提供するシステムである。

URLのqueryやfragmentには、検索語などの重要な記憶情報が含まれる。一方、アクセストークン、署名付きURL、Magic Link等の権限系シークレットが含まれる場合もある。

第三者への提供を将来的に想定しているため、単一ユーザー運用における自己責任だけを安全性の根拠とはしない。

## Findings

Slice 1Aの隔離PoCにより、以下を確認した。

1. 既知形式の権限系シークレットについては、限定的な自動マスキングが可能である。
2. 未知サービスの不透明な識別子については、URL文字列だけでは秘密情報か通常の識別子かを確実に区別できない。
3. 自動検出には誤検出・検出漏れの両方が存在する。
4. あるレコードで検出した秘密値を他レコードに伝播してマスキングすると、新たな検索オラクルが発生する。
5. 秘密値のdistinct数によって処理上限を設ける方式でも、成功・失敗の違いが情報漏洩経路になり得る。
6. Release Projectionを利用した局所的マスキングは設計可能だが、権限系シークレットの完全保護を保証するものではない。

PoCでは139テストが成功した。ただし、危険な挙動の再現テストも含むため、製品全体の安全性を保証する結果ではない。

## Decision

**権限系シークレットの追加マスキング、Release Projectionの製品導入、トークン・オラクルへの追加対策の採否を保留する。**

現時点では以下とする。

- 新しい自動マスキング機構を製品に組み込まない。
- 既存のPrivacy Gate、資格情報検出、Vault公開承認、fail-closed設計は維持する。
- Vault原本、既存の収集・公開契約を本件を理由に変更しない。
- 全レコードへの秘密値一致伝播マスキングは、既知の検索オラクルを生じるため採用しない。
- 未知の権限系シークレットを完全検出できると主張しない。
- 本件の最終判断はPOが保持する。

本決定は、権限系シークレット漏洩のリスクを解決済みとみなすものではない。

## Consequences

### Positive

- 検証不十分な防御機構による新たな情報漏洩経路を導入しない。
- URL・検索語等の記憶の忠実性を維持する。
- 今後の検証結果を踏まえて、入口保護と出口保護を再評価できる。

### Negative / Residual Risks

- Privacy Gateを通過したURL等に権限系シークレットが含まれる場合、MCP経由でAIに公開され得る。
- 未知サービスのMagic Link、署名付きURL、opaque token等を完全に検出することはできない。
- Prompt Injectionが成功した場合、公開済みデータから秘密情報を探索される可能性が残る。
- 第三者利用に向けた追加の安全対策が未確定である。

## Reconsideration Triggers

以下の場合、POによる再検討を行う。

- 一般公開または第三者への配布を判断する前
- 新たな有効な保護方式が提示された場合
- 実際のシークレット漏洩または重大な検証結果が確認された場合
- Page Vault／MHTML等の公開データ範囲が拡大する場合
- MCPに書き込み系ツールや新たな外部連携を追加する場合
